# Vefforritun 1, 2026: Verkefni 3, Skalanlegt CSS og tæki & tól sýnilausn

Sýnilausn á [verkefni 3](https://github.com/vefforritun/vef1-2026-v3), byggð á [sýnilausn verkefnis 2](https://github.com/vefforritun/vef1-2026-v2-synilausn).

Þarf að hafa Node.js og npm uppsett til að keyra þetta verkefni.

```bash
npm install
npm run dev # keyra þróunaruhverfi
npm run build # búa til keyrsluútgáfu í dist/
npm run lint # keyra Stylelint
npm run lint:fix # láta Stylelint laga það sem það getur
npm run format # keyra Prettier
```
